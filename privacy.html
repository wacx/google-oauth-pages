Privacy Policy

Last updated: 2026-09-26

cc2obs-fitbit is a personal automation project built and operated by a single individual developer, for that developer's own personal use only. It is not a public service, has no other users, and no one else can sign up or connect an account to it.

What data this app accesses

This app uses the Google Health API with the following OAuth scopes:

  • googlehealth.activity_and_fitness.readonly
  • googlehealth.activity_and_fitness.writeonly

It writes workout sessions (exercise type, start/end time, duration, and estimated calories) that the developer manually logs through a private Discord bot, so that this data is recorded alongside the developer's other fitness data in Google Health / Google Fit.

How this data is used and stored

All data handled by this app belongs to, and is used only by, the developer. Workout data is also copied into the developer's own private, local note-taking system (Obsidian) running on the developer's own computer. Nothing is sent to, stored on, or processed by any third-party server, and this data is never sold, shared, or used for advertising.

Data retention and deletion

The developer can revoke this app's access to their Google Account at any time from Google Account permissions. Revoking access immediately stops any further data exchange.

Contact

Questions about this policy can be directed to the developer via github.com/wacx.
